# PokeRips 🃏

**Rip. Reveal. Collect.**

PokeRips is a Pokémon-inspired digital card ripping platform. Browse packs, open them with exciting animations, and build your collection.

## Features

- 🃏 **Pack Opening** — Quick Rip and Cinematic Rip modes
- ✨ **Card Reveals** — 3D flip animations with rarity-specific effects
- 💰 **Demo Wallet** — Simulated $100 starting balance
- 🏛️ **My Vault** — Personal card collection with sorting & filtering
- 📜 **Rip History** — Complete opening history
- 🌈 **Holographic Effects** — Special visuals for Ultra Rare and Chase cards

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
